# Evora client downloads

## [Download Evora-Launcher.exe](https://github.com/Nova-74/qt-client-release/releases/latest/download/Evora-Launcher.exe)

This is the only file players need to download. Run it, click **Download**, then **Play**. The game installs and updates automatically under Local AppData/Evora.

The remaining files support automatic updates or release verification. Do not download, extract or join `.part000` files manually. The starter ZIP is an optional alternative containing the same launcher.

Client source code remains private. GitHub's automatic “Source code” archives contain only this downloads repository's documentation.
